# 报告阅读方式

在“检查结果”选择目标，或从任务详情进入报告，然后选择“易懂版 / 技术版”。切换不会扫描目标，也不会修改人工确认状态。

- 易懂版默认展示已有记录的白话解释、检查规模、配置加固建议与局限。没有证据时会提示无法评价；任务结束不是安全认证。
- 技术版保留发现审核、证据编号与合并入口。正式漏洞导出仍只包含已人工确认且有关联证据的发现。
- MD、HTML 导出跟随当前阅读方式；证据包包含当前目标或当前任务范围内的证据。易懂版导出保留线索/待确认状态，不把这些记录升级为已验证漏洞。
- 点击“刷新报告”重新读取已保存结果。切换目标或任务会重新载入对应摘要。

后端新增经过本地鉴权的 `GET /api/targets/{id}/report-summary?job_id=...`。原报告导出增加 `audience=easy|technical`，默认仍为 technical，保留旧客户端行为。摘要通过确定性代码生成，不调用模型，不发送原始响应或凭证。
