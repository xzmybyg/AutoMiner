# 数据整合

使用 `scripts/consolidate_data.py` 离线整合不同工作库。操作前必须关闭桌面窗口与后台服务；工具检查运行进程及文件锁，并先备份数据库、密钥与设置。

记录按 ID 去重，不因地址相同重写目标身份。主库已有记录优先，冲突来源单独存档。来源凭证使用来源工作库密钥解密，再用主库密钥加密；缺少密钥或关联不完整时停止，不静默丢弃凭证。未结束任务标记为停止，未完成请求标记为中断，不重放请求。

主库使用项目 `data/desktop` 或用户已登记的位置，详见 [固定工作库](fixed-storage.md)。迁移后必须通过实际运行的桌面 API 核对存储标识和数据数量，并重新启动确认；只比较路径字符串不足以判断使用了同一个文件。

损坏数据库与不能验证的片段应保留在本地备份中，不能作为已验证证据导入。数据库、日志、证据与备份均不纳入源代码仓库。
