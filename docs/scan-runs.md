# 一次检查，只显示一个任务

“任务记录”现在按用户发起的一次检查展示，而不是按执行器的内部步骤逐条展示。

- 普通手动任务仍显示一条。
- 自动检查的多个模板、多个模型轮次和所有内部检测步骤统一归入该次自动检查。
- 同目标其他次检查不会按地址或时间猜测合并；历史整合必须明确指定步骤 ID，拒绝重复归属、跨目标记录和进行中的历史任务。

点击总任务的“查看详情”，可查看所有接口与模板、内部检测步骤、执行日志、审计记录和验证回放。“查看本任务报告”及易懂版/技术版导出均汇总该次检查的证据，不包含其他次任务。

原始 job、evidence、finding、verification 和审计 ID 没有重写或删除。内部步骤仍可按原 ID 追溯，但不再挤占默认任务列表。总任务只是一层展示与范围汇总，不会进入执行队列，也不会绕过原有授权、请求预算或停止逻辑。

统一启动入口是项目根目录 `AutoMiner.exe` 或 `启动AutoMiner.cmd`。release 下的目录保留作构建历史，不需要选择它们。
