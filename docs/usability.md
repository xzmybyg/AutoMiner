# 易用性调整

主入口为“我的应用、开始检查、检查记录、检查结果”，模型与出口设置归入“设置”。高级接口导入、发现及自定义检查保留在“开始检查”的折叠区；AI 自动流程也在此处，按需开启。

我的应用包含应用列表与测试账号两个视图。账号提供验证登录、更新凭证；更新不会创建重复账号，会终止使用旧凭证的未结束任务并清除旧验证状态。验证使用用户指定的范围内 GET 身份接口，匿名和账号各一次，使用既有网关和请求预算。匿名被拒绝、账号返回明确标识以及可选预期角色时才标为可用；HTML 200、公开接口及不完整响应不认定有效。验证证据关联任务，列表显示时间与原因。已验证会话在检查中被 401 拒绝时停止该任务后续请求，提示更新并重新验证。不会自动登录或刷新凭证。

开始检查采用三步引导：选择目的、账号与已登记 GET 接口、确认范围和预算。公开检查使用响应基线规则；后台身份对照要求所选账号已验证。可记住该目标上次选择的目的、预算和接口编号，不保存凭证到浏览器。尚无接口时，引导进入发现/导入；此引导不会宣称已发现全部接口，也不执行业务写入。

创建任务后直接进入检查概览，显示已确认发现、待确认线索、未请求接口、失败请求、最近事件及下一步建议。详细请求、验证回放、日志和审计仍可切换。报告默认易懂版，用户可切换技术版。

验证：新增账号验证测试覆盖真假身份响应、角色不符、截断、跨范围、更新凭证中止旧任务及失效会话阻断。隐藏浏览器使用独立合成数据验证引导、创建任务跳转、账号管理与验证表单，不使用真实目标请求进行界面验证。
